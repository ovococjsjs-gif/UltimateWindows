# 06. Каталог твиков: формат файла данных

Твики Оптимизатора описаны не в коде, а в файле данных
[`src/UltimateWindows.Modules.Optimizer/Catalog/tweaks.json`](../src/UltimateWindows.Modules.Optimizer/Catalog/tweaks.json).
Файл встраивается в сборку. Чтобы добавить, поправить или убрать твик, достаточно изменить этот файл и пересобрать программу.

Программа читает файл один раз, при первом обращении к каталогу, и проверяет его целиком (`TweakCatalogLoader`).
При любой ошибке каталог не загружается, а сообщение называет твик и поле. Те же проверки выполняются тестами
при каждой сборке на GitHub, поэтому версия с ошибкой в каталоге не соберётся.

## Пример

```json
{
  "id": "disk.disable-superfetch-sysmain",
  "category": "DiskAndFileSystem",
  "icon": "DSK",
  "title": "Отключить Superfetch (SysMain) на быстрых NVMe / SSD",
  "explanation": "Убирает постоянную фоновую подгрузку на диск от службы SysMain (рекомендуется для SSD).",
  "impact": "Без фоновых чтений диска",
  "risk": "Low",
  "requiresAdministrator": true,
  "requirements": { "bestOnSolidStateSystemDrive": true },
  "actions": [
    { "type": "registry", "hive": "HKLM", "key": "SYSTEM\\CurrentControlSet\\Services\\SysMain", "name": "Start", "kind": "dword", "value": 4, "default": 2 }
  ]
}
```

## Поля твика

| Поле | Обязательно | Значение |
|---|---|---|
| `id` | да | Уникальный идентификатор: строчные латинские буквы, цифры и дефисы, части разделены точкой. Идентификатор хранится в профилях пользователей, поэтому у существующего твика его не меняют. |
| `category` | да | Раздел списка: `SystemAndPerformance`, `DiskAndFileSystem`, `AppTelemetry`, `QuietBackgroundAndAds`, `UiAndResponsiveness`, `GamingAndLatency`, `SecurityAndClarity`. |
| `icon` | да | Короткая метка раздела: `SYS`, `DSK`, `APP`, `PRV`, `UI`, `GAM`, `SEC`. |
| `title`, `explanation`, `impact` | да | Тексты для пользователя, своими словами: название для списка, одно-два предложения о том, что изменится, и короткая метка пользы. |
| `risk` | да | `Safe`, `Low`, `Moderate`, `Attention`, `Advanced`, `High`, `Critical`. Начиная с `High` твик считается опасным: он не входит в наборы и включается только после отдельного подтверждения. |
| `requiresAdministrator` | да | `true`, если твик меняет что-либо за пределами `HKCU`. |
| `requirements` | нет | Условия применимости, см. ниже. |
| `actions` | да | Список действий, не меньше одного. |

## Условия применимости (`requirements`)

| Поле | Значение |
|---|---|
| `minWindowsBuild`, `maxWindowsBuild` | Сборки Windows, на которых параметр существует. Например, `22000` — первая сборка Windows 11. Вне этих границ твик включить нельзя. |
| `bestOnSolidStateSystemDrive` | `true`: на жёстком диске твик не рекомендуется и требует согласия пользователя. |
| `batteryWarning` | Текст предупреждения. На устройствах с батареей твик не рекомендуется и требует согласия. |

Если программе не удалось выяснить факт о компьютере, условие не мешает включить твик.

## Действие `registry`

| Поле | Обязательно | Значение |
|---|---|---|
| `type` | да | `"registry"`. Пока это единственный тип; службы, задачи планировщика и встроенные приложения появятся следующими. |
| `hive` | да | `HKLM`, `HKCU`, `HKCR` или `HKU`. |
| `key` | да | Путь раздела через обратную косую черту. В JSON она удваивается: `"SOFTWARE\\Policies\\Microsoft"`. |
| `name` | да | Имя значения. Пустая строка — значение «(По умолчанию)». |
| `kind` | да | `dword` или `string`. |
| `value` | да | Что записать при включении твика. Для `dword` — число (`1`, `4294967295`) или строка в шестнадцатеричной записи (`"0x1F"`). Для `string` — текст в кавычках. |
| `default` | нет | Содержимое значения в чистой Windows. При возврате к стандарту оно записывается обратно. Если поля нет, значения в чистой Windows не существует, и возврат к стандарту удаляет его. |

Откат через «Машину времени» от поля `default` не зависит: перед каждой записью программа сохраняет то, что было
в реестре на самом деле, и возвращает именно это.

## Наборы (`presets`)

Раздел `presets` в начале файла — это готовые наборы: название и список идентификаторов твиков. Набор `recommended`
обязателен. Опасные твики в наборы не входят.

## Что проверяется при загрузке

- Нет неизвестных и повторяющихся полей; все обязательные поля заполнены.
- Идентификаторы не повторяются; наборы ссылаются только на существующие твики.
- Куст реестра и вид значения — из разрешённого списка; число помещается в 32 разряда.
- Твик, который пишет за пределы `HKCU`, помечен `requiresAdministrator`.
- Одно и то же значение реестра не меняется дважды в одном твике.
- Изменения, ослабляющие защиту Windows (Защитник, SmartScreen, защита ядра, контроль учётных записей), допустимы
  только в твиках с риском `High` и выше.
- Вмешательство в активацию и лицензирование Windows запрещено всегда.

## Откуда брать содержимое

Какой параметр реестра за что отвечает — это факт, и узнавать его можно откуда угодно: из документации Microsoft,
из наблюдений, из чужих программ как из справочника. Названия и пояснения пишутся своими словами.

Тексты, файлы данных и код чужих программ в каталог не копируются. Это относится и к программам с открытым кодом,
чья лицензия запрещает копирование или требует распространять производные работы на тех же условиях
(Optimizer, BleachBit, privacy.sexy, MinerSearch, Winapp2 и подобные). Подробнее — раздел 8
в [`05-AUDIT-AND-GAP-ANALYSIS.md`](./05-AUDIT-AND-GAP-ANALYSIS.md).
