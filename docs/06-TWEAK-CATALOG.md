# 06. Каталог настроек Оптимизатора: формат файлов данных

Настройки Windows, которые включает Оптимизатор (в коде и в командах они называются твиками), описаны не в коде,
а в файлах данных. Чтобы добавить, поправить или убрать настройку, достаточно изменить файл и пересобрать программу.

Сейчас в каталоге 191 настройка в 13 разделах и 4 готовых набора.

## Где лежат файлы

Папка [`src/UltimateWindows.Modules.Optimizer/Catalog/Data/`](../src/UltimateWindows.Modules.Optimizer/Catalog/Data/).
Каждый файл `*.json` из неё встраивается в сборку. Программа читает файлы по порядку имён и складывает их содержимое,
поэтому имена начинаются с числа:

| Файл | Раздел в программе |
|---|---|
| `10-privacy.json` | Конфиденциальность |
| `20-ads.json` | Реклама и подсказки |
| `25-ai.json` | Copilot и функции ИИ |
| `30-explorer.json` | Проводник и рабочий стол |
| `35-taskbar.json` | Панель задач и «Пуск» |
| `40-performance.json` | Система и быстродействие |
| `45-gaming.json` | Игры |
| `50-disk.json` | Диск и файловая система |
| `55-network.json` | Сеть |
| `60-updates.json` | Обновления Windows |
| `65-security.json` | Защита |
| `70-services.json` | Службы и фоновые задачи |
| `80-apps.json` | Программы |
| `90-presets.json` | Готовые наборы |

Раздел настройки задаёт её поле `category`, а не имя файла: деление на файлы нужно только для удобства правки.
Внутри раздела настройки показываются в том порядке, в котором записаны.

Каталог читается один раз, при первом обращении, и проверяется целиком (`TweakCatalogLoader`). При любой ошибке
он не загружается, а сообщение называет файл, настройку и поле. Те же проверки выполняются тестами при каждой сборке
на GitHub, поэтому версия с ошибкой в каталоге не соберётся.

## Устройство файла

```json
{
  "schemaVersion": 2,
  "tweaks": [ { … }, { … } ],
  "presets": { … }
}
```

`schemaVersion` обязателен и равен `2`. Из `tweaks` и `presets` нужен хотя бы один.

## Пример настройки

```json
{
  "id": "svc.disable-maps",
  "category": "BackgroundServices",
  "title": "Отключить обновление автономных карт",
  "explanation": "Отключает службу и задания, которые скачивают и обновляют карты для приложения «Карты». Если карты не скачаны, вы ничего не потеряете.",
  "risk": "Safe",
  "actions": [
    { "type": "service", "name": "MapsBroker", "startup": "disabled", "default": "automaticDelayed" },
    { "type": "task", "path": "\\Microsoft\\Windows\\Maps\\MapsUpdateTask", "enabled": false },
    { "type": "task", "path": "\\Microsoft\\Windows\\Maps\\MapsToastTask", "enabled": false }
  ]
}
```

## Поля настройки

| Поле | Обязательно | Значение |
|---|---|---|
| `id` | да | Уникальный идентификатор: строчные латинские буквы, цифры и дефисы, части разделены точкой (`privacy.disable-something`). Идентификатор хранится в файлах профилей пользователей, поэтому у существующей настройки его не меняют. |
| `category` | да | Раздел: `Privacy`, `AdsAndSuggestions`, `AiFeatures`, `Explorer`, `TaskbarAndStart`, `Performance`, `Gaming`, `DiskAndStorage`, `Network`, `WindowsUpdate`, `Security`, `BackgroundServices`, `Applications`. |
| `title` | да | Название для списка. Говорит, что сделает настройка: «Отключить…», «Скрыть…», «Показывать…». |
| `explanation` | да | Одно-три предложения своими словами: что изменится для пользователя и что он потеряет. |
| `risk` | да | Уровень риска, см. ниже. |
| `restart` | нет | Когда изменение вступит в силу: `none` (сразу; так считается, если поля нет), `explorer` (после перезапуска Проводника), `signout` (после повторного входа), `reboot` (после перезагрузки). |
| `requirements` | нет | Условия применимости, см. ниже. |
| `actions` | да | Список действий, не меньше одного. Одна и та же цель в настройке встречается один раз. |

Нужны ли права администратора, программа определяет сама: они нужны для всего, кроме записи в `HKCU`.

### Уровень риска (`risk`)

| Значение | Метка в программе | Правила |
|---|---|---|
| `Safe` | Безопасно | Побочных эффектов нет. Может входить в наборы. |
| `Low` | Есть побочный эффект | Пользователь что-то теряет, и это названо в пояснении. Может входить в наборы. |
| `Moderate` | С оговорками | Подходит не всем. В наборы не входит. |
| `High` | Опасно | Ослабляет защиту или может нарушить работу Windows. В наборы не входит, скрыта, пока не отмечено «Показать опасные», включается только после отдельного подтверждения (в командной строке — с ключом `--force`). |

### Условия применимости (`requirements`)

| Поле | Значение |
|---|---|
| `minWindowsBuild`, `maxWindowsBuild` | Сборки Windows, на которых параметр существует. Например, `22000` — первая сборка Windows 11. Вне этих границ настройку включить нельзя. |
| `installedAny` и `installedNote` | Задаются вместе. `installedAny` — список разделов реестра вида `HKLM\\SOFTWARE\\Пример`; если ни одного из них нет, настройку включить нельзя, а `installedNote` объясняет почему («OneDrive не настроен в этой учётной записи»). |
| `bestOnSolidStateSystemDrive` | `true`: если система стоит на жёстком диске, настройка не рекомендуется и требует согласия. |
| `batteryWarning` | Текст предупреждения. На устройствах с батареей настройка не рекомендуется и требует согласия. |

Если программе не удалось выяснить факт о компьютере, условие не мешает включить настройку.

## Действия

### `registry` — значение реестра

```json
{ "type": "registry", "hive": "HKCU", "key": "Software\\Microsoft\\Пример", "name": "Enabled", "kind": "dword", "value": 0, "default": 1 }
```

| Поле | Обязательно | Значение |
|---|---|---|
| `hive` | да | `HKLM`, `HKCU`, `HKCR` или `HKU`. |
| `key` | да | Путь раздела через обратную косую черту, без неё в начале и в конце. В JSON она удваивается: `"SOFTWARE\\Policies\\Microsoft"`. |
| `name` | да | Имя значения. Пустая строка — значение «(По умолчанию)». |
| `kind` | да | `dword` или `string`. |
| `value` | да | Что записать при включении. Для `dword` — число (`1`, `4294967295`) или шестнадцатеричная запись в кавычках (`"0x1F"`). Для `string` — текст в кавычках. |
| `default` | нет | Содержимое значения в чистой Windows; при выключении настройки оно записывается обратно. Если поля нет, значения в чистой Windows не существует, и выключение его удаляет. |
| `removeEmptyKey` | нет | `true`: после удаления значения удалить и раздел, если он опустел. Допустимо только без `default`. Нужно там, где Windows смотрит на само наличие раздела. |

Тип запуска службы через реестр менять нельзя (запись в `…\Services\<имя>\Start` отклоняется): для этого есть действие `service`.

### `service` — тип запуска службы

```json
{ "type": "service", "name": "DiagTrack", "startup": "disabled", "default": "automatic" }
```

| Поле | Обязательно | Значение |
|---|---|---|
| `name` | да | Короткое имя службы (`DiagTrack`), а не отображаемое название. |
| `startup` | да | Тип запуска при включённой настройке: `automatic`, `automaticDelayed`, `manual`, `disabled`. |
| `default` | да | Тип запуска в чистой Windows; он возвращается при выключении настройки. |

Служба, которой назначен тип `disabled`, сразу останавливается.

### `task` — задание планировщика

```json
{ "type": "task", "path": "\\Microsoft\\Windows\\Maps\\MapsUpdateTask", "enabled": false }
```

| Поле | Обязательно | Значение |
|---|---|---|
| `path` | да | Полный путь задания: начинается с обратной косой черты, содержит папку и имя. |
| `enabled` | да | Состояние задания при включённой настройке. Обычно `false` — задание отключается. При выключении настройки состояние меняется на противоположное. |

Удаление встроенных приложений Windows в каталог не входит: оно делается вручную на вкладке «Приложения» и через
«Машину времени» не откатывается.

## Как программа применяет настройку

1. Читает текущее состояние каждой цели и сохраняет его для отката.
2. Вносит изменение, читает цель ещё раз и сверяет с ожидаемым.
3. Если хотя бы одно действие не удалось, возвращает назад всё, что успела изменить в этой настройке.
4. Записывает точку отката в «Машину времени»: одну на настройку или одну на весь набор.

Службы или задания может не быть на конкретном компьютере (другая редакция или сборка Windows). Такое действие
пропускается. Состояние настройки программа определяет по тем целям, которые есть:

| Состояние | Когда |
|---|---|
| Включена | Все существующие цели в нужном состоянии. Переключатель включён. |
| Включена частично | В нужном состоянии только часть целей. Переключатель выключен, на строке метка; включение доводит настройку до конца. |
| Выключена | Ни одна цель не в нужном состоянии. |
| Недоступна | Ни одной цели на этом компьютере нет. |

Откат через «Машину времени» от полей `default` не зависит: программа возвращает то, что было в системе на самом деле
перед изменением. Поля `default` нужны для выключения настройки переключателем и для определения её состояния.

## Наборы (`presets`)

```json
"presets": {
  "gaming": {
    "title": "Игры",
    "description": "Убирает то, что мешает в играх: фоновую запись, случайные окна и лишние фоновые задачи.",
    "tweaks": [ "gaming.disable-game-dvr", "taskbar.hide-widgets" ]
  }
}
```

Ключ набора пишется строчными латинскими буквами, цифрами и дефисами (`clean-ui`). Набор `recommended` обязателен.
В наборы входят только настройки с риском `Safe` или `Low`. Перед применением программа показывает список
и применяет только отмеченное.

## Что проверяется при загрузке

- Нет неизвестных и повторяющихся полей; все обязательные поля заполнены и имеют нужный вид.
- Идентификаторы настроек и ключи наборов не повторяются; наборы ссылаются только на существующие настройки
  и не содержат настроек с риском выше `Low`.
- Куст реестра, вид значения, тип запуска службы — из разрешённых списков; число помещается в 32 разряда.
- Действие что-то меняет: `value` отличается от `default`, `startup` отличается от `default`.
- Одна и та же цель не меняется дважды в одной настройке.
- Правила безопасности (`TweakSafetyGuard`), они же действуют при ручном управлении службами и заданиями:
  - лицензирование и активацию Windows, а также службы, без которых Windows не работает, менять нельзя никогда;
  - всё, что ослабляет защиту (Защитник, SmartScreen, контроль учётных записей, брандмауэр, обновления,
    теневые копии и восстановление системы), допустимо только в настройках с риском `High`.

## Как добавить настройку

1. Откройте файл нужного раздела и добавьте объект в список `tweaks` — на то место, где настройка должна стоять в списке.
2. Если настройка безопасна для всех, добавьте её идентификатор в подходящий набор в `90-presets.json`.
3. Отправьте изменение в репозиторий. Сборка на GitHub загрузит каталог, проверит его на настоящей Windows
   и покажет ошибку, если она есть.
4. Проверить настройку на своём компьютере можно командами `tweak-info <id>` (что именно изменится),
   `tweak-enable <id>` и `tweak-disable <id>`.

## Откуда брать содержимое

Какой параметр Windows за что отвечает — это факт, и узнавать его можно откуда угодно: из документации Microsoft,
из наблюдений, из чужих программ как из справочника. Названия и пояснения пишутся своими словами.

Тексты, файлы данных и код чужих программ в каталог не копируются. Это относится и к программам с открытым кодом,
чья лицензия запрещает копирование или требует распространять производные работы на тех же условиях.
Подробнее — раздел 8 в [`05-AUDIT-AND-GAP-ANALYSIS.md`](./05-AUDIT-AND-GAP-ANALYSIS.md).
